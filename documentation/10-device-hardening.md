# Cisco Device Hardening

## Overview

Basic hardening techniques were applied to both the router and switch to improve the security of management access.

---

# Hardening Measures

Implemented security controls include:

- Password encryption
- SSH Version 2
- RSA key generation
- Login banner
- Session timeout
- Limited SSH authentication retries
- Disabled DNS lookup

---

# SSH Configuration

Remote administration is performed using SSH Version 2.

Configuration includes:

- Local user authentication
- RSA encryption keys
- Secure remote login
- Authentication timeout
- Limited login retries

---

# Administrative Security

Management access is protected through:

- Local administrator accounts
- Encrypted passwords
- Secure login banner
- Idle session timeout

These measures reduce the attack surface and improve the security of Cisco network devices.
